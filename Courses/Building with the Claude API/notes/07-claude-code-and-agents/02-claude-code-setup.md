# Claude Code Setup

**Claude Code** = a terminal-based coding assistant that helps with code-related tasks.

## Core Capabilities

- Search / read / edit files
- Advanced tools (web fetching, terminal access)
- MCP client support, for expanded functionality via MCP servers

## Setup Process

1. Install Node.js (check with the `npm help` command)
2. Run `npm install` to install Claude Code
3. Run the `claude` command in your terminal to log in to your Anthropic account

**Full setup guide:** docs.anthropic.com

## MCP Client Functionality

Claude Code can consume tools from MCP servers, extending its capabilities well beyond basic file operations.
