# Anthropic Apps

Two deployed applications by Anthropic that demonstrate agent architecture: **Claude Code** and **Computer Use**.

## Claude Code

A terminal-based coding assistant that serves as an example of agent architecture.

## Computer Use

A toolset that expands Claude's capabilities beyond text generation, letting it interact with a computer's GUI.

## Key Purpose

Both apps demonstrate agent concepts and provide practical examples for understanding agent design and implementation.

## Setup Process

Involves terminal configuration, for use with Claude Code on sample projects.

## Agent Connection

Both applications exemplify how agents work, serving as learning models for building effective agents of your own.
