# Text Embeddings

A numerical representation of text meaning, generated by an embedding model.

## What an Embedding Model Does

Takes text as input, outputs a long list of numbers (typically in the range -1 to +1).

## What the Numbers Mean

Each number is a score representing some *unknown* quality or feature of the input text. In theory, each number scores a different aspect (topic relevance, sentiment, etc.) — but the exact meaning of each dimension is opaque to users.

## Semantic Search

Uses text embeddings to find chunks related to a user's question in a RAG pipeline. This solves the core search problem: matching a user query to the most relevant document chunks.

## RAG Pipeline Process

```
extract text chunks
  → user submits a query
  → find related chunks via semantic search
  → add relevant chunks as context to the prompt
```

## Implementation

Anthropic recommends **Voyage AI** for embedding generation. Requires a separate account/API key, but is free to start and easy to integrate via SDK.

## Key Insight

Embeddings enable **semantic similarity** matching, rather than plain keyword matching — allowing for much better understanding of text relationships during retrieval.
